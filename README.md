A personal portfolio website built from scratch wtih ReactJS and Tailwind CSS to showcase my personal hardware and software projects, state my education background, and also link my contact information.

## Inspiration
This project serves as a way for me to showcase my engineering and hardware projects. Built as a single-page application, it features a custom-styled, futuristic, and astronomical-themed black/blue website that has all the projects on it, and I'll be able to add more as I make more projects. It allows me to easily showcase my skills and projects to applications and any other people I need to show.

I was originally procrastinating on building my personal website, so I decided to use this hackc lub opportunity to kill two birds with one stone. The reason for that I am currently working on a more difficult drone quadcopter project for Hack Club. However, I want to start a Hack Club in my high school, but the application on Hack Club's website says the leader of the club (me) has to have shipped a project to Hack Club. Since the drone project is a little complicated and I've faced some setbacks, I decided to do something simple to unlock my status. By finishing and shipping this personal website, I hopefully kill 2 birds with 1 stone, and be able to start my club soon and hang up posters.

## Tech Stack
Frontend: HTML, CSS, ReactJS
Styling: Tailwind CSS, Custom Flexbox styling for animations
